01301 permanent

旧静态页 → 门户锚点

传统站点最常见的迁移需求：旧页面 301 到新地址，保住搜索权重。

rewrite ^/about\.html$ /portal#about permanent;
预期：地址栏变为 /portal#about，自动滚动到“关于我们”。
访问 /about.html →
02302 redirect

短链接入口

临时跳转用 302，浏览器不长期缓存，适合活动入口与二维码短链。

rewrite ^/go/admin$ /login redirect;
预期：地址栏变为 /login，状态码 302。
访问 /go/admin →
03捕获组 + 参数

路径参数改写

把 /news/年/月/日 拆成三个捕获组，拼成查询参数并跳到新闻锚点。

rewrite ^/news/(\d{4})/(\d{2})/(\d{2})/?$ \ /portal?date=$1-$2-$3#news permanent;
预期：跳转后新闻区出现 参数 date=2026-10-18 的提示。
访问 /news/2026/10/18 →
04内部重写

地址不变，内容替换

内部重写不会返回 30x，浏览器地址栏保持不变，这是 rewrite 与跳转的本质区别。

rewrite ^/demo/old-page\.html$ /rewrite-lab.html last;
预期：地址仍是 /demo/old-page.html，内容却是本演示台。
访问 /demo/old-page.html →
05大小写归一

大写路径重定向

把用户误输入的大写路径统一到小写正式地址，避免出现 404。

rewrite ^/PORTAL$ /portal permanent;
预期：地址栏由 /PORTAL 变为 /portal。
访问 /PORTAL →
06rewrite + 代理

接口版本前缀改写

对外暴露 /api/v1，内部改写后转发给后端，后端无需感知版本前缀。

location /api/v1/ { rewrite ^/api/v1/(.*)$ /$1 break; proxy_pass http://127.0.0.1:8080; }
预期：在服务器上执行下面的 curl，返回 token。
curl -X POST http://127.0.0.1/api/v1/login \ -H 'Content-Type: application/json' \ -d '{"username":"admin","password":"admin123"}'

同一需求，为什么有的地方不用 rewrite

需求 推荐做法 原因
Vue history 路由回退 try_files $uri $uri/ /index.html; 先判断真实文件是否存在，静态资源不会白白走一次正则
去掉 /prod-api 前缀 proxy_pass http://127.0.0.1:8080/; 末尾斜杠即可完成，无需 rewrite
固定地址跳转 return 301 https://...; 不跑正则，性能更好，语义更清晰
旧地址迁移、带参数改写、内部换文件 rewrite ... [last|break|redirect|permanent] 需要正则与捕获组，其他指令做不到
